# Community palettes

Color schemes based on well-known terminal themes, converted to the
equisdots palette format from the **base16** scheme definitions collected by
the [tinted-theming](https://github.com/tinted-theming) project
(base16-schemes / schemes, MIT licensed). Each file keeps its original
scheme name and author attribution in the `author` field.

Notes:
- These palettes are included as color references only. All names and
  trademarks belong to their respective authors/projects; there is no
  affiliation or endorsement.
- Colors were mapped from the base16 layout (base00-base0F) to the
  equisdots layout used by the shell (color0-color15). See the converter
  notes in this README if you need the exact mapping:
  `color0=base00, color1=base08, color2=base0B, color3=base0A, color4=base09,
  color5=base0E, color6=base0C, color7=base05, color8=base03, color9=base08,
  color10=base0B, color11=base0A, color12=base09, color13=base0E,
  color14=base0C, color15=base07`.
- Background/foreground use base00/base05.
